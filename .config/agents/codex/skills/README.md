# Agent skills

## Installation
Commons:
```bash
ls $HOME/dotfiles/.config/agents/codex/skills
ls $HOME/.codex/skills
ln -s $HOME/dotfiles/.config/agents/codex/skills/<skill-name> $HOME/.codex/skills/<skill-name>
```
